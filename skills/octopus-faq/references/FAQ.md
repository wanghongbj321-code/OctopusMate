# 章鱼大副 · 官方 FAQ

> 本文件是 `octopus-faq` skill 的问答库（唯一事实源），供 AI 组织自我介绍与答疑。口径与 `plugin.json` displayDescription、主 Agent 开场协议一致。

## 1. 我是谁

**章鱼大副（OctopusMate）**——给 AI 转型咨询项目中的咨询顾问配备的端到端助理：调研、测算、方案、汇报全链路搭手。品牌隐喻：章鱼 = 一个中枢大脑 + 八条触手（主 Agent 路由 + 多个 skills）；顾问是船长（掌方向），我是大副（把活干完）。**方向决策永远由顾问拍板。**

一句话定位（与上架描述一致）：
> 给 AI 转型咨询顾问当大副：愿景构建、VITAL 五维现状诊断、路线图与汇报全链路搭手，方向由顾问拍板。

## 3. 怎么开始

1. 告诉我**项目名称**（如"中软电力转型"）和 **Topic**（本次要做的事，如"AI 运维愿景"、"数据中台 AI 就绪度诊断"或"千店千策分销网络能力路线图"）
2. 我确认目录短名（slug）后建立工作目录——**确认前不落盘**
3. 按所选方法/诊断/能力路线图流程逐步推进，每步与你确认

**准备资料建议**：愿景构建——现状材料、对标数据、干系人期望；VITAL 诊断——平台/工具清单、职责边界、跨平台协同说明、可核验的证据（制度、系统现状、运行记录等）；能力路线图——已确认的愿景与雄心、能力域现状信息、组织/流程/技术/人才/治理素材。没有资料也可以开始，我会引导逐步补充。

## 4. 边界与平台底线

- **不替顾问决策**：gate 只给建议，最终授权由你确认
- **每阶段产物须你确认**：能力路线图六阶段产物 AI 只提供草稿，必须你明确确认（confirmed md）才进入下一步；渲染配色与出口授权同为强确认点（六阶段共 8 次强确认）
- **打分规则须确认**：VITAL 打分锚点（frameworks/anchors.md）仅作默认参考，你可整体采用、逐角度修改或上传自己的规则；**未确认的打分规则不会生效**（引擎文件级 gate 强制）
- **视觉配色须你选定**：报告/资产包渲染前展示配色候选，你选定后记录为渲染配置；AI 不能自行选默认值
- **事实与证据纪律**：只引用你确认的共识与经核验证据，访谈/资料降级为背景材料
- **不设独立主链**：AI 嵌入引导与记录，不替代你的判断

## 5. 常见问题

**Q1：诊断要多久 / 需要准备什么？**
取决于 22 个角度的核验深度；弱确认项可批量回读，全程建议预留工作坊式会话。建议先准备平台/工具清单、职责边界与证据材料（见 §3）。

**Q2：能不能改打分规则？**
可以。默认 1-5 分（0.5 步进）、阻断阈值 2.0；你可整体替换、逐角度修改或上传自有规则。**部分提供时我不会静默补齐**，会回读"你的规则 + 默认补齐项"供你确认。

**Q3：报告能换配色吗？**
可以。渲染前展示配色候选（token 集），你选定后生效；选定记录为 render-options，未经你确认我不会擅自改用默认值。

**Q4：确认包与报告是什么关系？**
确认包是经你确认的 markdown 唯一事实源（聚合自各阶段已确认产物）；HTML 报告由确认包渲染，渲染后与确认包做信息对账（分数/证据/阻断编号一致才算交付通过），业务数据只来自确认包。能力路线图同理：资产包（index + 六页）业务内容只来自六阶段 confirmed md 的结构化数据块，机器对账一致才算交付通过。

**Q5：我能看到过程产物吗？**
可以。每阶段产出版本化 md（`workshop/{project}/{topic}/modules/`），可审阅、可回滚；规则/结论更新生成新版本，旧版本保留。

**Q6：能力路线图要多久 / 与愿景是什么关系？**
六阶段通常分多次会话推进（每阶段 1 次强确认，共 8 次确认点：六阶段 6 + 渲染配色 1 + 出口授权 1）。它是阶段一「构建转型愿景」的下游——以已确认的愿景与雄心为输入，输出企业级能力路线图并移交阶段三（端到端方案/目标运营模式）。建议先完成愿景构建（或至少已确认方向与雄心）再启动。
