# 北极星指标法：半天工作坊快速愿景构建

以单一北极星指标锚定方向的快速愿景路径。适配场景：时间受限、需要先对齐方向再深潜的转型团队。

## 触发条件

- 「用北极星指标法构建愿景」「北极星指标愿景工作坊」「半天快速愿景」

## 工作流

1. **现状痛点与价值卡点**（manifest 01）：转型核心痛点与卡点，需有依据
2. **确定北极星指标**（manifest 02）：1 个可度量的北极星指标（指标定义卡），责任方/数据源齐备
3. **未来新闻稿与一句话愿景**（manifest 03）：撰写转型成功后的未来新闻稿（标题/正文/FAQ），反推一句话愿景，明确为客户/员工/业务创造的结果与价值
4. **愿景六特质自检**（manifest 04）：复用 `_shared/T5` 六特质自检，核心项为可想象 + 可沟通

## 平台出口

第 4 步完成后由平台出口层接管：输出契约校验 / 确认裁决（用户授权节点）/ 确认包 HTML 渲染（黑灰专业配色）。契约满足规则：字段集合与 7 步法一致，填充深度允许简化。

## 边界

- 步骤定义与 gate 在本方法 manifest；出口层与 AI 铁律为平台底线，方法不可覆盖
- 六特质自检 / 未决清单为平台共享模板（`_shared/T5`、`_shared/T10`），本方法不复制改写
- 方法引擎按 manifest 逐步推进；确认授权节点由主 Agent 在顾问确认后写入 state.json
