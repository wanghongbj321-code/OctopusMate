# 北极星指标定义卡（步骤 02）

> 选定 **1 个** 可度量指标代表转型成功；须满足：单一、可度量、有数据源、有责任方。

| 维度 | 内容 |
|---|---|
| 指标名称 | （如：订单一次通过率） |
| 定义 | （如：无需人工干预即可完成全流程的订单占比） |
| 现状基线 | （当前值 + 数据时间） |
| 目标值（3 年） | （分年轨迹：Y1 / Y2 / Y3） |
| 数据源 | （系统/报表/口径） |
| 责任方 | （value owner） |
| 待量化标记 | （暂无法量化的填「待量化」并登记未决项） |

**使用规则**：指标必须单一（聚焦）；多指标竞争时由顾问拍板取舍；「待量化」项 → 登记未决项（拟裁决=降级为假设时，须在输出契约 `validationPlan` 补验证路径）。
