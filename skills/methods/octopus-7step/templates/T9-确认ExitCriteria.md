# T9 · 确认 Exit Criteria（步骤 07）

> 来源：构建转型愿景.md v2.1 §5 T9。决策门放行标准——避免确认环节退化为形式签字。

| 判定项 | 标准 | 结果 |
|---|---|---|
| 未决项裁决完成 | 未决条件清单逐项完成「补充/降级/移出」三选一，无无主项 | 通过 / 有条件 / 不通过 |
| 关键利益相关者签署 | 发起人 + 业务/IT/运营负责人签署 | 通过 / 有条件 / 不通过 |
| 资源承诺 | 资金/人才/时间承诺已确认 | 通过 / 有条件 / 不通过 |
| 变更控制规则生效 | 审批人与修订流程已明确 | 通过 / 有条件 / 不通过 |

**三态判定**：
- **通过**：全部判定项通过 → 甲方确认，进入渲染
- **有条件通过**：附未决项裁决结果与遗留清单 → 可进入渲染，遗留项随确认包移交下游
- **不通过**：核心判定项（未决项无主）失败 → 回指修订，不得进入确认
