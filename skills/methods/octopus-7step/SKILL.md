# Octopus 7 步法：深潜完整版愿景构建

完整咨询路径的愿景构建方法（7 步骤 + T1-T10 模板 + AI 引导剧本）。适配场景：客户决策链完整、可投入多轮工作坊的转型项目。

## 触发条件

- 「用 Octopus 7 步法构建愿景」「7 步法愿景工作坊」「完整愿景构建」

## 工作流

1. **界定转型问题与变革必要性**（manifest 01）：为什么必须转型、现在不动的代价
2. **明确战略前提、关键取舍与转型边界**（manifest 02）：战略级联、取舍声明、边界约束
3. **拓展未来可能性并推导关键转型变化**（manifest 03）：情景矩阵、信念假设、证据分级
4. **构建转型愿景**（manifest 04）：归并未来状态主题、愿景共创工作坊、未来某天叙事稿、六特质自检（`_shared/T5`）、愿景创造的结果与价值
5. **确定转型雄心、变革范围与推进速度**（manifest 05）：雄心四维（深度/广度/规模/速度）+ 雄心量化表（T6）+ 速赢资金引擎（T7）
6. **检验并完善转型愿景与雄心**（manifest 06）：五项检验 + 验证计划（T8），未决项登记与裁决
7. **确认转型愿景与雄心**（manifest 07）：未决项裁决 + exit criteria（T9）+ 确认包组装，由平台出口层接管

## 平台出口

第 7 步完成后由平台出口层接管：输出契约校验 / 确认裁决（用户授权节点）/ 确认包 HTML 渲染（黑灰专业配色）。

## 边界

- 步骤定义与 gate 在本方法 manifest；出口层与 AI 铁律为平台底线，方法不可覆盖
- 六特质自检 / 未决清单为平台共享模板（`_shared/T5`、`_shared/T10`），本方法不复制改写
- 方法引擎按 manifest 逐步推进；步骤 04/07 的授权节点由主 Agent 在顾问确认后写入 state.json
