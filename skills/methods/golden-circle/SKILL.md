# 黄金圈法：使命驱动愿景构建

从「为什么」出发的愿景构建路径（Simon Sinek 黄金圈）。适配场景：转型信念尚未对齐、需要从使命共识起步的团队。

## 触发条件

- 「用黄金圈法构建愿景」「Why-How-What 愿景工作坊」

## 工作流

1. **Why**（manifest 01）：使命与信念——为什么必须转型，不从技术/工具出发
2. **How**（manifest 02）：制胜方式——如何与众不同，检查与 Why 一致
3. **What**（manifest 03）：未来状态愿景——具体做什么，复用 `_shared/T5` 六特质自检
4. **平台出口**：4 步完成后由平台出口层接管（契约校验 / 确认裁决 / 渲染，同 7 步法与北极星法）

## 边界

- 步骤定义与 gate 在本方法 manifest；出口层与 AI 铁律为平台底线，方法不可覆盖
- 六特质自检 / 未决清单为平台共享模板（`_shared/`），本方法不复制改写
