# T13 · 下一步行动表（全阶段共用 · 质量门收尾）

> 来源：方法论 v1.2 §5 T13。每阶段质量检查后应产出下一步行动表（麦肯锡决策收尾惯例），行动与未决项一一对应，作为进入下一阶段的执行入口。

| 下一步行动 | 责任 owner | 时限 |
|---|---|---|
| （示例）补充 C5 库存口径裁决证据（U-03） | 组合治理 | 步骤 04 前 |
| （示例）更新同行基准数据 | 数据负责人 | 步骤 03 前 |
| ... | ... | 步骤 NN 前 / 持续（月度复审） |

## 使用规则

1. 每阶段质量门收尾时生成本表，行动与未决项（T12）一一对应
2. owner 必须明确（业务 / 技术 / 数据 / 变革负责人），时限必须给出（步骤 NN 前 或 持续复审）
3. 本表为进入下一阶段的执行入口：未决行动未完成前，对应裁决事项保持开放
