# T5 · 愿景质量自检（Kotter 六特质，跨方法共享模板）

> 来源：构建转型愿景.md v2.1 §5 T5。跨方法通用（Octopus 7 步法步骤 04 / 北极星指标法第 ④ 步复用）。
> 平台共享模板：`skills/methods/_shared/`，方法不得改写（§6.1 模板复用规则）。

| 特质 | 自检问题 | 判定 |
|---|---|---|
| 可想象 Imaginable | 听众能在脑中形成具体未来画面？ | 是 / 否 |
| 可取 Desirable | 对客户、员工、利益相关者是否值得追求？ | 是 / 否 |
| 可行 Feasible | 目标现实可达，虽需努力但不荒谬？ | 是 / 否 |
| 聚焦 Focused | 是否提供清晰决策指引而非面面俱到？ | 是 / 否 |
| 灵活 Flexible | 是否允许在执行中保留个体主动性？ | 是 / 否 |
| 可沟通 Communicable | 5 分钟内讲清并引发理解与兴趣？ | 是 / 否 |

**三态判定**：
- **通过**：六项全「是」
- **有条件通过**：仅非核心特质（可取/可行/聚焦/灵活）未满足 ≤3 项 → 登记未决项，可继续
- **回指**：核心特质（**可想象 / 可沟通**）任一「否」→ 回指步骤 04 重做，不得带核心缺失前进
