## 三个时间跨度

| 时间跨度 | 时间参考 | 阶段目标和举措重心 |
|---|---|---|
| 第一阶段：夯实基本盘 | 最初 3-12 个月 | 推动战术性改善、成本优化和现金流改善；弥补关键能力缺口；以较快产生实际结果的举措证明战略能够产生实际结果 |
| 第二阶段：增长与规模化 | 随后 12-24 个月 | 强化运营系统，为长期愿景建立条件；执行更复杂、投资更大的举措并验证影响 |
| 第三阶段：再定位与重塑 | 24 个月以后 | 配置一至两个由战略引导的重大投入，推动市场扩张、产品创新、并购或业务重塑 |

> 时间区间是经验参考，不是固定三年日历，也不是举措自动归类规则。

## 使用规则

1. 三阶段逐行填写：阶段目标 / 重点举措 / 关联能力 / 依赖 / 资源投资 / 价值验证 / 成果指标 / 责任主体 / 治理关注点
2. 与里程碑甘特图配套：本表呈现三阶段逻辑，甘特图呈现时间推进与 M/G/D 节点
3. 成果指标列覆盖四类：业务 / 能力 / 采用 / 风险（对齐 T11A）
4. 不形成项目级排期、上线计划或系统设计（P5 边界）
