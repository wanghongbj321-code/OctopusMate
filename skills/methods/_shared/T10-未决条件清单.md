## 使用规则

1. 每项必填 1-5 列：编号 / 登记步骤 / 未决内容 / 登记原因（答不上来 / 证据缺失 / 争议）/ 拟裁决方式（补充 / 降级 / 移出）
2. 第 6 列「裁决结果」在出口确认环节（7 步法内步骤 07）逐项填写并归档
3. 裁决三选一：**补充回答 / 降级为假设（标注影响面与验证计划）/ 移出转型范围**
4. 降级为假设的项，必须在输出契约 `validationPlan` 中有对应验证计划（条件必填，见开发计划 §4）
5. 不留无主项：每项均有裁决结果或明确遗留去向
