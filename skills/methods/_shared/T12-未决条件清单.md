## 使用规则

1. 每项必填：编号 / 登记步骤 / 未决内容 / 影响面 / 登记原因（答不上来 / 证据缺失 / 争议）/ 证据强度（A/B/C）/ 责任人 / 拟裁决方式
2. **编号规则**：未决项按阶段独立编号（U-01、U-02…）；跨阶段延续的未决项在新阶段标注「承接 NN·U-xx」（原编号），确保同一事项跨阶段可追溯
3. **裁决四选一**：补充回答 / 降级为假设（标注影响面与验证计划）/ 移出范围 / 带入下游验证；降级项必须在输出契约对应验证计划中体现
4. **关键未决项（如条件能力裁决）应在步骤 06 决策门显式管理**，裁决结果登记于"裁决结果"列并触发路线图滚动更新（R5）
5. 不留无主项：每项均有裁决结果或明确遗留去向
