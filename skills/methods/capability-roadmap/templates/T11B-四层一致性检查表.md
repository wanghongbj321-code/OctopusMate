# T11B · 四层一致性检查表（步骤 06）

> 来源：方法论 v1.2 §5 T11B。从 Strategy、Business Model、Operating Model、Enabling Technology and Infrastructure 检查整体一致性。
> 三态判定：通过 / 有条件通过 / 回指（核心层失败回指对应前置步骤）。

| 层次 | 检查要点 | 结论 | 未决项 |
|---|---|---|---|
| Strategy | 路线图是否支撑愿景、雄心与战略方向 | 通过 / 有条件通过 / 回指 | ... |
| Business Model | 是否支撑价值主张、客户结果与盈利模式 | 通过 / 有条件通过 / 回指 | ... |
| Operating Model | 是否与目标运营模式、组织与流程要求一致 | 通过 / 有条件通过 / 回指 | ... |
| Enabling Technology & Infrastructure | 是否与平台、数据、集成与技术债演进约束一致 | 通过 / 有条件通过 / 回指 | ... |

## 使用规则

1. 四层逐项检查；结论三选一（通过 / 有条件通过 / 回指）
2. 核心层（Strategy）失败 → 回指步骤 04 或步骤 03 修订（路线图与雄心速度冲突回指 04；战略目标变化回指 03）
3. 有条件通过项登记未决项（T12），带入阶段成果确认或下游验证
4. 本表结论为步骤 06 Q-gate「路线图完整性」的核心判定输入
