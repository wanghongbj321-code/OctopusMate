## 使用规则

1. 行 = 关键价值流或客户结果；列 = 支撑能力、风险、目标结果与指标
2. **校验结论**四选一：覆盖完整 / 有条件通过 / 需下钻 / 需补证据
3. 识别跨价值流共用能力（如某底座能力出现在全部价值流中 → 规模化前置能力候选）
4. 步骤 03 复核时，结合成熟度与价值流校验更新"是否重点能力候选"结论（P8 价值流校验）
