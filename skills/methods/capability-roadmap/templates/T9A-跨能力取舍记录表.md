## 举措取舍维度

| 取舍维度 | 需要回答的问题 |
|---|---|
| 战略必要性 | 不做该举措，愿景或雄心是否无法实现 |
| 价值确定性 | 价值假设是否有足够证据，能否在阶段内验证 |
| 依赖关键性 | 是否是其他高价值举措的前置或并行基础 |
| 风险暴露 | 不做是否带来合规、安全、韧性、客户或声誉风险 |
| 组织承受力 | 是否超出业务、技术、数据、资金或变革吸收能力 |
| 学习价值 | 是否能快速验证关键假设、降低后续不确定性 |

## 使用规则

1. 六维取舍依据逐项记录（高/中/低 或 可承受/紧张/不可承受），不设加权汇总
2. **取舍结论**：前置 / 并行 / 延后 / 移出四选一；移出必须记录原因（进入非重点/非举措理由存档）
3. 决策记录列登记裁决场合（会议/负责人/日期），供组合治理接口（O7）追溯
