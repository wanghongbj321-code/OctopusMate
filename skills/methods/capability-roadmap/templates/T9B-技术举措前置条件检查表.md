# T9B · 技术举措前置条件检查表（步骤 05）

> 来源：方法论 v1.2 §5 T9B。技术举措必须同步检查 Insights、Process、Talent、Governance 是否需提前或并行弥合，防止"只建系统不建能力"。

| 技术举措 | Insights 前置 | Process 前置 | Talent 前置 | Governance 前置 | 结论 |
|---|---|---|---|---|---|
| （示例）门店级策略引擎建设 | 数据标准化先行（统一门店/商品主档） | 策略-执行-复盘流程需并行定义 | 策略分析师角色与培训需并行 | 策略归属与复审机制需并行建立 | 数据先行 + 治理并行 |
| ... | ... | ... | ... | ... | 数据先行 / 流程先行 / 治理并行 / 全维度前置确认 |

## 使用规则

1. 每项技术举措逐维检查四类前置（Insights / Process / Talent / Governance）是否需提前或并行弥合
2. **结论**：数据先行 / 流程先行 / 治理并行 / 全维度前置确认——四选一或组合
3. 检查结果作为步骤 05 举措映射（T9）的依赖补充，进入步骤 06 跨能力依赖关系
